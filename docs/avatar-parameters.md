# アバター側で用意するパラメーター

`python -m vrcdj.run` は、次のアバターパラメーターを VRChat に OSC で送ります。
アバターの Expression Parameters に同じ名前・型で追加し、Animator でこの値に合わせて動くようにしてください。

## パラメーター一覧(同期ありで合計 49 bit)

| 名前 | 型 | 値 | 用途 |
|---|---|---|---|
| `DJ_Active` | Bool | 起動中 true、終了時 false | DJ 用レイヤー全体のオン/オフ |
| `DJ_HandL` | Int | 下の動作番号 | 左手の動作 |
| `DJ_HandR` | Int | 下の動作番号 | 右手の動作 |
| `DJ_ValueL` | Float | 0.0〜1.0 | 左手が触っているつまみ・フェーダーの位置。ジョグは 0.5 が停止 |
| `DJ_ValueR` | Float | 0.0〜1.0 | 右手の同上 |
| `DJ_XFader` | Float | 0.0(左)〜1.0(右) | クロスフェーダーの位置(手が離れていても保持) |
| `DJ_Emote` | Int | 0=なし、1〜8=左デッキ、9〜16=右デッキ | SAMPLER モードのパッドで出す表情・特殊動作。押してから 2 秒保持 |

## 動作番号(DJ_HandL / DJ_HandR)

| 番号 | 動作 | Value を使うか |
|---|---|---|
| 0 | 待機(デッキの上で構える) | |
| 1 | CUE を押す | |
| 2 | PLAY/PAUSE を押す | |
| 3 | ジョグを回す | ○(0.5=停止、0/1 に近いほど速い) |
| 4 | つまみを回す(TRIM・EQ・CFX・レベル類) | ○ |
| 5 | チャンネルフェーダー | ○ |
| 6 | テンポスライダー | ○ |
| 7 | ループ系ボタン(LOOP IN/OUT・RELOOP・CUE/LOOP CALL) | |
| 8 | BEAT SYNC | |
| 9 | パッドを叩く | |
| 10 | ロータリーセレクター・LOAD | |
| 11 | クロスフェーダー | ○ |
| 12 | BEAT FX のボタン | |
| 13 | パッドモード切り替え | |
| 14 | その他のボタン | |

## 送り方のルール

- ボタンは押した瞬間にその番号になり、最低 0.35 秒保ってから 0 に戻ります。同期で他の人に届く長さにするためです。
- つまみ・フェーダー・ジョグは、最後に触ってから 0.6 秒で 0 に戻ります。
- 同じボタンを続けて押すと番号が変わらないまま続くので、ボタンの動作アニメーションは「押す動きのループ」にしておくと自然に見えます。
- クロスフェーダーなど、どちらの手でもよい操作は、空いている方の手に振られます。

## Animator の組み方(デスクトップモード想定)

- 左手・右手で別々のレイヤーを作り、アバターマスクでそれぞれの腕と手だけを動かします。
- 各レイヤーは `DJ_HandL`(または R)の番号でステートを切り替え、遷移時間は 0.1 秒前後にします。
- Value を使う動作は、2 つのポーズを `DJ_ValueL`(または R)でブレンドする 1D ブレンドツリーにします。例: フェーダーなら「手前」と「奥」のポーズ。
- `DJ_Active` が false のときは DJ 用レイヤーの重みを 0 にして、普段のアバターに戻します。
- Modular Avatar を使うと、元のアバターを壊さずにこれらのレイヤーとパラメーターを追加できます。
